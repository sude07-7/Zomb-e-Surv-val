🧟 Zombi Hayatta Kalma (Python / Pygame)
Python ve Pygame aracılığıyla geliştirilmiş 2D üstten kuşbakışı bir zombi hayatta kalma oyunudur.
Bu proje; oyun hissi, dalga (dalga) sistemi ve gerçek zamanlı savaş mekaniklerine odaklanır.

🎮 Özellikler
🧠 Dalga (Wave) yapısal zorluk sistemi (giderek artan zorluk)
⏱ Hayatta kalma süresi (ne kadar yaşadığın)
💥Ekran sallanma efekti (özellikle tank zombilere vuruşa oy verme)
🧟 Farklı zombi türleri:
Normal Zombiler
Hızlı Zombiler
Tank Zombileri (yüksek can, güçlü saldırı)
🎯 Yönlü nişan alma sistemi (WASD + Enter)
👤 4 yönlü oyuncu hareketi
💣 Çarpışma tabanlı savaş sistemi
📈 Skor sistemi
❤️ Can sistemi ve oyun bitiş ekranı
🎯 Kontrolör
Tuş	**
W / A / S / D	Oyuncu hareketi
Girmek	Ateşleme
🧩 Oyun Mekanikleri
Onun dalgası (dalga) zorluğunu arttırır
Zombilerin zamanında daha hızlı ortaya çıkması olur
Zombi skor ve dalga ilerlemesini sağlar
Tank zombiler vurulunca ekran seçimi (sallama) olur
Can sıfırlanınca oyun ısırıcı
🛠 Kullanılan Teknolojiler
Python 3
Pygame
🚀 asama
pip install pygame
python game.py
